Resumo para a prova

Componentes: Ax = |A|·cos θ · Ay = |A|·sen θ · |A| = √(Ax² + Ay²)

Soma: |R|² = |A|² + |B|² + 2·|A|·|B|·cos θ · Diferença: |D|² = |A|² + |B|² − 2·|A|·|B|·cos θ

θ é o ângulo entre A e B quando os dois saem do mesmo ponto. Casos especiais: mesmo sentido, |R| = |A| + |B| (o maior possível); sentidos opostos, |R| = |A| − |B| (o menor); perpendiculares, Pitágoras. Para somar ou subtrair, o caminho mais seguro é sempre o das componentes: x com x, y com y.
